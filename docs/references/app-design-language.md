# App Design Language

## Control Owner

Global `/Users/gurusharan/.codex/AGENTS.md` owns instruction control. This file owns Like-minded app UI information architecture and copy density.

## Rule

One tab, one job. Default UI is scannable state and action. Explanation appears only inside edit, feedback, or explicit detail surfaces.

## Tabs

- Meet: RSVP state, upcoming/past meets, pre-meet teaser, static live-call prototype, and post-meet selection entry.
- Circles: current circle, fit reasons, concern CTA, browse cards, and circle detail.
- Communities: broader interest and taste entry points. No private profile read and no circle fit reasons.
- Profile: private voice profile, live listening/saving state, and compact captured signals.
- Soulmate: opt-in, post-meet match list, and connection status. No general inbox outside Soulmate.

## Visual Language

- Canvas: warm cream with deep green actions and high-contrast ink copy.
- Type: small uppercase section labels, serif display headlines, compact SF body text.
- Cards: cream surface cards for state/control; gradient cards for circles, communities, and meet teasers.
- Motion: keep entrances and state transitions soft; do not animate basic reading content.
- Dark mode surfaces are intentional only for voice capture, live call, and Soulmate.

## Copy Rules

- One short subtitle per screen.
- Cards get a title plus controls or one supporting line.
- Model-generated long prose lives in Profile only.
- Circle fit reasons live in Circles only.
- Interest tags live in Communities and Soulmate match detail only.
- Meetup info lives in Meet only except the circle-detail next-meet row.
