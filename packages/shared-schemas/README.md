# Shared Schemas

Shared data contracts for app, backend, AI orchestration, and matching logic.

## Schemas

- `schemas/profile-signal.schema.json` - first placeholder contract for user profile signals derived from onboarding.
- `schemas/reflect-place-connect.schema.json` - MVP slice contract for reflection, starter circle placement, and a consent-aware connection path.

These schemas are intentionally small until product and privacy decisions settle.
