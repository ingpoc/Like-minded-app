# Shared Schemas

Shared data contracts for app, backend, AI orchestration, and matching logic.

## Schemas

- `schemas/profile-signal.schema.json` - current lightweight contract for user profile signals derived from onboarding.
- `schemas/reflect-place-connect.schema.json` - MVP slice contract for reflection, starter circle placement, and a consent-aware connection path.

These schemas are intentionally small for the TestFlight MVP. Expand them only when app/API payloads or privacy requirements need a durable contract.
