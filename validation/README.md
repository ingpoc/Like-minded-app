## Conventions

- Each screen has a `.md` (human) and `.json` (machine) ledger.
- Control `result` ∈ {`pass`, `fail`, `blocked`, `pending`}.
- Screens with no mockup reference are flagged `mockup_missing: true` and will be authored from `DESIGN.md` during runtime testing.
- Screenshots land in `<platform>/screenshots/<NN>-<name>.png`.
